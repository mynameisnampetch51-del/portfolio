OPERATIONAL Phishing URL Detector

Multi-layer suspicious link checker, modeled on real systems like Google Safe Browsing: 8 heuristic rules run entirely in the browser (IP-as-hostname, typosquatting, URL shorteners, etc.), backed by an ML classifier (logistic regression trained on the UCI PhiUSIIL dataset, 235,795 URLs) via a backend API that fetches and inspects the real page content.

OPERATIONAL Password Strength Checker

Measures an existing password's strength on a needle gauge — scored from real entropy, not just length. Flags easy-to-guess patterns (common passwords, repeated or sequential characters, keyboard patterns). Runs entirely in the browser; the password never leaves it.

OPERATIONAL Password Forge

Generates secure new passwords with crypto.getRandomValues (not Math.random), using rejection sampling to avoid bias. Choose your own length and character set; each character stamps in one at a time instead of appearing all at once. Linked to Password Strength Checker via the top bar.

OPERATIONAL Cube Net Visualizer
